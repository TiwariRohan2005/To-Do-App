# 📝 Full Stack Todo App (Flask + JavaScript)

A modern full-stack Todo application with authentication, persistent storage, and dynamic UI.

## 🚀 Features

- 🔐 User Registration & Login (Session-based)
- ✅ Add, Delete, Toggle Todos
- 💾 Persistent storage using SQLite database
- 🔄 Auto-sync between frontend & backend
- 🎨 Clean UI with responsive design
- 🗑️ Delete tasks with bin icon
- ⚡ Fast, dynamic updates using Fetch API

---

## 🛠️ Tech Stack

### Frontend
- HTML
- CSS
- JavaScript (Vanilla JS)
- Font Awesome

### Backend
- Python (Flask)

### Database
